# NASA Tech Talks — card art brief

Drop finished images into `public/tech-talks/cards/` using the **exact filename** in each row.
I wire them up and verify every one. No filename guessing — the page loads `<slug>.jpg`.

## Global spec (applies to every card)

| Setting | Value |
| --- | --- |
| Aspect | **4:5 vertical** |
| Size | **1600 × 2000 px** (min 1200 × 1500) |
| Format | `.jpg`, quality ~85, under ~600 KB |
| Look | Photorealistic / cinematic photography, shallow depth of field |
| Subject | **One dominant physical subject**, human or tactile wherever possible |
| Read | The image must make sense **before** anyone reads the title |

**Must NOT contain:**
- Any burned-in text, captions, watermarks or UI — the page draws all typography
- Giant NASA logos or meatballs; mission patches
- Floating holograms, sci-fi HUD overlays, lens-flare clutter
- A generic "astronaut floating in space" that would fit any card

**Composition note:** the page overlays type on the **bottom ~45%** and small labels in the
**top-left and top-right corners**. Keep those zones visually calm — the subject reads best in the
upper-middle or as a large shape at one side. Mid-to-dark tonality works best; white type sits on top.

**On real people:** several cards name real speakers. I won't generate photoreal images of real
individuals, and I'd advise against it here too — a fabricated photo of a named NASA engineer on a
public NASA-affiliated page is a genuine misrepresentation risk. Prefer hands, hardware, environment,
or an unidentifiable figure. If you do choose to depict a speaker, use a real photo you have rights to.
